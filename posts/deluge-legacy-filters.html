0x1: Restoring Classic Deluge Filter Character in Community Firmware 1.2

DATE: 2026-08-07 | PROJECT: DELUGE_FIRMWARE

Overview

Synthstrom Audible’s open-source Deluge community firmware introduced amazing DSP features, including morphable filters and driven ladder filter modes. However, these changes altered the original frequency response and antialiased saturation of official firmware 4.1.4. Presets crafted under pre-community firmware versions sounded noticeably different.

This project implements dedicated, selectable Legacy Filter Modes for both Low-Pass and High-Pass filters, ensuring complete backwards compatibility with older presets while preserving all community features.

Technical Root Cause Analysis

During testing, an array indexing mismatch was uncovered when accessing SpecificFilter modes: 1. FilterMode::HPLADDER_LEGACY was added after SVF_NOTCH, but SpecificFilter::toMode() calculated variant offsets based on numForVariant order: {kNumLadders, kNumSVF, kNumHPLadders}. 2. Because FilterFamily::HP_LADDER assumes its base offset starts at kNumLadders + kNumSVF (index 7), placing HPLADDER_LEGACY before HPLADDER caused out-of-bounds array reads in the filter lookup tables.

Fix Applied:

  • Reordered FilterMode::HPLADDER and FilterMode::HPLADDER_LEGACY in filter_config.h so enum indices match SpecificFilter variant offsets.
  • Synchronized HPFMode options order in hpf_mode.h.

Filter Modes Summary

Low-Pass Filter Modes (LPF)

Menu Display Internal Mode Description
12dB Legacy TRANSISTOR_12DB_LEGACY Original clean pre-community LP12 response
24dB Legacy TRANSISTOR_24DB_LEGACY Original clean pre-community LP24 response
12dB Ladder TRANSISTOR_12DB Community firmware morph/saturation LP12
24dB Ladder TRANSISTOR_24DB Community firmware morph/saturation LP24
Drive TRANSISTOR_24DB_DRIVE Driven 24dB ladder filter

High-Pass Filter Modes (HPF)

Menu Display Internal Mode Description
HP Ladder HPLADDER Community firmware HP ladder (with input FM morphing)
HP Legacy HPLADDER_LEGACY Original pre-community HP ladder (no FM morphing, level 2 saturation)

Automatic Preset Mapping

XML preset loading in filter_config.cpp automatically maps legacy preset tags: * "12dB" -> FilterMode::TRANSISTOR_12DB_LEGACY * "24dB" -> FilterMode::TRANSISTOR_24DB_LEGACY * "HPLadder" -> FilterMode::HPLADDER_LEGACY

Newer community presets save under "12dBNew", "24dBNew", and "HPLadderNew".
